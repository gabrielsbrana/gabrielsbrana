## Public portfolio

### [BizMetrics CLI](https://github.com/gabrielsbrana/bizmetrics-cli) · Python / Analytics
A command-line tool for bringing marketing and analytics data into a repeatable workflow. The project includes connectors for Google Analytics 4, Meta Ads, and demo data; SQLite caching; and CSV/Excel exports.

**Engineering signals:** modular connectors · CLI design · typed Python · automated tests and CI

### [Defense Sector Market Analysis](https://github.com/gabrielsbrana/analise-mercado-defesa) · Streamlit
An interactive analytical app for exploring historical market data from defense-sector companies, with CSV ingestion, data cleaning, weekly-return calculations, trend thresholds, and visual summaries.

**Stack:** Python · Streamlit · Pandas · NumPy · Altair

### [Empirical Network Analysis](https://github.com/gabrielsbrana/analise-redes-empiricas) · Data Science
A reproducible notebook-based study of ten empirical networks, covering network structure, degree distributions, path metrics, and centrality measures including PageRank, Katz, eigenvector, and betweenness.

**Stack:** Python · Jupyter · NetworkX · Pandas · SciPy · Matplotlib
